## Brand & Style

This design system drives a premium commercial fitness management ecosystem engineered for facility owners, front-desk managers, and elite trainers. The brand personality balances executive authority with athletic momentum—precise, vigilant, and energetic without resorting to juvenile visual clutter. 

The aesthetic style merges **Corporate / Modern** operational reliability with **Tactile Performance** touches: crisp visual data density, high-contrast indicators, razor-sharp geometric alignment, and instant-glance actionable touch targets optimized for busy turnstiles and fast-paced gym floors. The interface evokes relentless operational control, prestige hospitality, and effortless speed.

## Colors

The palette establishes an authoritative sports-performance atmosphere through a structured dark-and-light hierarchy:

- **Primary (`#0F172A`) & Deep Navy Tint (`#1E293B`):** Commands structural chrome, navigation bars, headers, primary action buttons, and dominant metrics.
- **Secondary Athletic Teal (`#0D9488` / `#14B8A6`):** Highlights active telemetry, session logs, primary brand accents, and check-in success states.
- **Electric Cobalt (`#2563EB`):** Drives interactive links, primary software utilities, system notifications, and direct communication hubs.
- **Surfaces & Neutral (`#FFFFFF`, `#F8FAFC`, `#64748B`):** Multi-layered card backgrounds and high-density tabular canvases that resist eye strain in direct gym-floor lighting.
- **Status Accents:**
  - **Active / Paid:** Emerald Green (`#10B981`)
  - **Expiring / Pending:** Warning Amber (`#F59E0B`)
  - **Expired / Overdue / Alert:** Vibrant Coral Red (`#EF4444`)

Never apply vibrant colors as solid fills across large container surfaces; reserve energetic pigments exclusively for status pills, progress arcs, active states, and actionable iconography.

## Typography

The type system pairs the punchy, geometric structure of **Plus Jakarta Sans** for titles, numerical KPI badges, and member identifiers with the neutral legibility of **Inter** for dense tabular data and status labels. 

- Use tabular figures (`font-variant-numeric: tabular-nums`) across all revenue values, countdown timers, locker numbers, and check-in counters.
- `label-sm` is strictly uppercase for membership tags (`ACTIVE`, `EXPIRED`, `PENDING`), with letter-spacing expanded for clarity at micro-resolutions.

## Layout & Spacing

The layout operates on a fluid, adaptive responsive grid:
- **Mobile (< 768px):** Single-column stack with sticky bottom quick-action utility bars, edge margins of `1rem`, and a vertical flow prioritizing rapid search, turnstile check-ins, and high-priority alerts.
- **Tablet / Responsive (768px – 1199px):** 8-column layout split between live access feeds (left 5 columns) and context-aware member detail trays / quick drawers (right 3 columns).
- **Desktop (1200px+):** 12-column layout accommodating multi-metric performance graphs and persistent side navigation.

All touch targets across handheld viewports must meet a strict minimum bounding size of `44x44px`, even when rendered as compact utility icons.

## Elevation & Depth

Visual hierarchy uses a refined **Tonal Layer + Low-Contrast Border** strategy supplemented by subtle ambient shadows:

- **Flat Canvas:** The default foundation is `#F8FAFC`.
- **Card Surfaces:** Base containers use `#FFFFFF` bounded by a 1px border of `#E2E8F0` with an ambient shadow: `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)`.
- **Active / Focused Elevating Drawers:** Modal sheets and quick-action flyouts utilize `box-shadow: 0 10px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.08)`.
- **Header & Command Bar:** Sticky elements employ an ultra-subtle backdrop blur (`backdrop-filter: blur(12px)`) over a 90% opacity `#0F172A` header or `#FFFFFF` sub-bar to retain scroll context.

## Shapes

The design system standardizes on a **Rounded (`2`)** geometry profile to produce balanced, high-efficiency interactive touch surfaces:
- Standard buttons, input controls, chips, and member metric modules feature an 8px (`0.5rem`) corner radius.
- Cards, modal containers, and check-in swipe panels adopt a 16px (`1rem` / `rounded-lg`) corner radius.
- Circular avatars, icon-only utility triggers (WhatsApp, Phone), and system status dots use complete circular rounding (`9999px`).

## Components

### Action Buttons & Quick Action Trigger Strip
- **Primary Actions (Check-In, Renew):** Solid `#0F172A` background with crisp white typography. On hover or tap, transitions to `#1E293B`.
- **Athletic Accent (Quick Check-In Success):** `#0D9488` solid fill, conveying positive progression.
- **Communication Fast-Triggers:** Compact 36x36px or 40x40px rounded utility buttons. 
  - *WhatsApp Action:* Tinted soft mint (`#ECFDF5`) background with emerald green icon (`#059669`).
  - *Phone Call Action:* Tinted ice cobalt (`#EFF6FF`) with electric cobalt icon (`#2563EB`).

### Member & High-Density Operational Cards
- Cards feature member profile snapshots containing member photo/avatar, membership tier badge, days remaining, locker/assigned trainer, and direct operational buttons.
- Overdue and Expiring states apply a 3px solid left-edge border indicator (e.g., `#EF4444` for delinquent dues, `#F59E0B` for renewals due in < 7 days).

### Status Badges & Chips
- Status indicators utilize a light-tint container fill with contrasting, saturated medium-weight text:
  - **Active:** `#D1FAE5` background, `#065F46` label.
  - **Pending / Grace Period:** `#FEF3C7` background, `#92400E` label.
  - **Overdue / Expired:** `#FEE2E2` background, `#991B1B` label.

### Input Fields & Member Barcode Lookup
- Inputs use `#FFFFFF` background, a 1px border of `#CBD5E1`, and a 12px horizontal inset. Focused state triggers a 2px outer ring in Athletic Teal (`#0D9488`) without abrupt layout shifts.
- Built-in trailing action icons support instant camera/scanner input on mobile devices.

### Checkboxes, Switches & Radio Controls
- Styled switches feature high-contrast states: inactive slate `#CBD5E1` transitioning to athletic teal `#0D9488` when toggling gym access permissions, trainer assignments, or auto-renew agreements.
